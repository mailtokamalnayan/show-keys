# Show Keys privacy policy

Last change: 12 November 2026

Show Keys shows the keys you press at the bottom of the page. This policy tells you what the extension does with your data.

## What the extension reads

When you turn on the overlay, the extension reads each key you press on a web page. It uses the key name only to draw the key on the screen. After 1.5 seconds, the key goes away.

The extension does not read keys that you type in password fields.

## What the extension keeps

The extension keeps two settings in Chrome sync storage:

- Whether the overlay is on or off.
- The key style that you selected.

The extension does not keep, record, or log the keys you press.

## What the extension sends

The extension sends no data to a server. It makes no network requests. It has no analytics and no advertisements.

When you type in a frame inside a page, the extension sends the key name to the top of the same tab. It uses Chrome's own extension messages for this, so the web page cannot read them.

## Who sees your data

Nobody. The developer does not receive your data, and the extension does not sell or share it.
