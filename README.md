# Show Keys

A Chrome extension that shows the keys you press at the bottom center of the page. The keys look like flat Mac key caps.

## Install

1. Open `chrome://extensions`.
2. Turn on **Developer mode**.
3. Click **Load unpacked** and select this folder.
4. Click the extension icon and turn on **Show pressed keys**.

## Notes

- The overlay uses the Berkeley Mono font if it is installed on your computer. Else it uses Menlo.
- Keys typed in password fields do not show.
- Chrome does not let extensions run on `chrome://` pages.
